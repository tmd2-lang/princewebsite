# The Unkwn Wedding Palace — website concept

A concept redesign for The Unkwn Wedding Palace (wedding films, Silver Spring, Maryland).

Plain HTML, CSS and JavaScript: no build step. Deploy as a static site (e.g. Vercel, "Other" framework preset, no build command, output directory = repo root), or open locally with any static server:

```
python3 -m http.server 8000
```

Notes
- Wedding films stream from theunkwnpalace.com.
- The inquiry form is a front-end concept: submitting shows a thank-you screen but doesn't send anything yet. Connect it to an email service or HoneyBook before launch.
- Testimonials are placeholders, to be replaced with real reviews.
- Event photos from Pexels (credited in the footer). 3D camera built in code with Three.js.
